# OIBSIP_Datascience_Task3
Email Spam Detection with Machine Learning

1. Project Overview

This project focuses on classifying emails as spam or not spam (ham) using Machine Learning classification techniques. The model analyses the text of a message to decide which category it belongs to.

2. Project Objective

The main objective is to develop a classification model that can predict whether an email is spam or legitimate based on its text content.

3. Dataset Description

The project uses a labelled email/SMS spam dataset. Each record contains:

	•	Message Text
	•	Label (Spam or Ham)

4. Technologies Used

	•	Python
	•	Jupyter Notebook
	•	Pandas
	•	NumPy
	•	Matplotlib
	•	Seaborn
	•	Scikit-learn

5. Data Preprocessing

The dataset was examined to understand its structure and data quality. Null values and duplicate records were checked, and the labels were converted into numerical form. The message text was cleaned and converted into numerical features that machine learning algorithms can use.

6. Exploratory Data Analysis

Exploratory Data Analysis was performed to understand the differences between spam and legitimate messages.

Visualizations were used to identify patterns, such as the balance between the two classes and differences in message length and commonly used words.

7. Machine Learning

Classification algorithms were implemented to predict whether a message is spam or ham based on its text features.

8. Model Evaluation

The trained models were evaluated using appropriate classification evaluation metrics, including accuracy, precision, recall, F1-score and the confusion matrix, wherever applicable.

9. Conclusion

This project demonstrates how Machine Learning classification techniques can be used to detect spam emails.

It provided practical experience in text data preprocessing, exploratory data analysis, visualization and machine learning model evaluation.
